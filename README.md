
# 🚀 EclipseTech

<p align="center">
  <b>Always learning. Always building.</b><br>
  A powerful web-based session generator for Baileys bots with secure storage and one-click deployment.
</p>

---

## ✨ Features

- 🔐 Generate sessions for any Baileys bot  
- ☁️ Secure session storage using MEGA  
- 📱 Web-based QR pairing & Pair Code support  
- ⚡ Fast and lightweight  
- 🚀 One-click deployment support:
  - Heroku
  - Render
  - Koyeb
  - Self-hosting
